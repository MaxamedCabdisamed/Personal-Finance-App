# Personal-Finance-App
Income & Expense Tracker Web App

I'll create a comprehensive financial tracking application with all the features you've requested: CRUD operations, dashboard with charts, budget management, savings tracking, and a dual-column transaction table.

Features of this Income & Expense Tracker:
1.	Complete CRUD Operations:
o	Create, Read, Update, and Delete transactions
o	Edit and delete budgets and savings goals
o	All data persists using web local storage
2.	Interactive Dashboard:
o	Summary cards showing total income, expenses, balance, and budget remaining
o	Bar chart comparing income vs expenses over the last 7 days
o	Doughnut chart showing expense breakdown by category
3.	Transaction Management:
o	Add transactions (income or expense) via modal popups
o	Two-column layout showing income on the left and expenses on the right
o	Transaction details include title, amount, category, date, and description
4.	Budget Management:
o	Set monthly budgets by category
o	Visual progress bars showing spending vs budget
o	Alerts when you exceed budget limits
5.	Savings Goals:
o	Set savings goals with target amounts and dates
o	Track progress toward each goal
o	Visual progress indicators
6.	User-Friendly Interface:
o	Clean, modern design with intuitive navigation
o	Tab system to switch between transactions, budgets, and savings
o	Responsive layout that works on mobile and desktop
o	Sample data pre-loaded for first-time users
The application uses Chart.js for data visualization and stores all data locally in the browser using localStorage, so no server or database is needed. All features are accessible directly from the interface with clear visual feedback.
